# Sanjid × Kabir — Mother App

This repository contains the Mother App scaffold for the premium couple web app "Sanjid × Kabir". It's built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Zustand for state management.

This initial commit contains the core shell: global layout, responsive sidebar, dashboard and placeholder pages, global video UI (mock), notification center, and a modular registry to add modules later.

To run locally:

1. npm install
2. npm run dev


Architecture notes and next steps are in the README.
